# 📚 StudyProjects

Repositório dedicado a documentar minha jornada de aprendizado em programação — exercícios, desafios e pequenos projetos feitos durante os estudos.

A ideia aqui não é ter código perfeito, e sim registrar evolução: cada projeto representa um passo dentro da curva de aprendizado, com os erros e acertos que vieram junto.

## 🗂️ Projetos

| Projeto | Descrição |
|---|---|
| [Jogo da Adivinhação](./JogoAdivinhacao) | Jogo de adivinhar número, usando loop, condicionais e `Scanner`. |
| [Calculadora Java](./Calculadora-Java) | Calculadora com as 4 operações básicas, tratamento de divisão por zero e separação de responsabilidades em classes distintas. |

> A lista vai crescer conforme novos exercícios forem concluídos.
