\# Jogo da Adivinhação



Jogo simples em Java onde o computador escolhe um número aleatório e o usuário tenta adivinhar através de dicas de "maior" ou "menor".



\## Conceitos praticados

\- Estruturas de repetição (`while`)

\- Estruturas condicionais (`if/else`)

\- Leitura de entrada com `Scanner`

\- Geração de números aleatórios com `Random`

\- Contagem de tentativas



\## Como executar

```bash

javac JogoAdvinhacao.java

java JogoAdvinhacao

```



\## Exemplo de execução

```

Jogo da Advinhação!

\#-------------------#

Computador já escolheu o número dele. Agora é sua vez:

10

Número alto. Tente um menor:

5

Numero baixo. Tente um maior:

7

Agora sim você acertou. O numero era 7 e você precisou de 3 tentativas!

```
